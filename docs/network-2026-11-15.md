# Public query integration

- Local full suite: 131 tests passed. Jetson network suite: 30 passed.
- Voice stream retrieved public search data and emitted source metadata through
  the same interface used by the listener. One search completed in 0.415 seconds.
- Final deployed nonstream assistant path: weather forecast completed in 2.365
  seconds and public search in 0.414 seconds. Both returned valid source links.
  Timings exclude ASR, TTS and physical speaker output.
- An earlier weather request timed out and correctly reported failure. A later
  attempt succeeded; the final transport retries a transient failure once with
  bounded timeouts, and caches successful results for 60 seconds.
- Browser QA loaded the deployed result page through an SSH loopback tunnel,
  verified three source links and inspected the rendered 1024px layout. This is
  the deployed page, not a mockup. The direct Chrome LAN route was unavailable
  to the test browser; SSH and the device's own service remained accessible.
- Tests cover query-only outbound payloads, local-task routing, privacy/secret
  filtering, empty/challenge responses, response-size bounds, retry, cache times,
  city clarification and next-day weather follow-up. No paid credentials added.

The default general provider is the public Bing search RSS format. Its descriptions
can be stale/incomplete, and its result timestamps are not treated as publication
proof. This is retrieval of search snippets, not full-page research or authenticated
web automation. Results never execute tools. Weather is a structured forecast from
[Open-Meteo](https://open-meteo.com/en/docs) using its
[geocoding API](https://open-meteo.com/en/docs/geocoding-api).

Private work databases/history are not included in provider requests. Provider
questions are still sent to the corresponding third party, and the normal local
conversation history policy applies to spoken requests. Source files were backed
up under the device's ignored runtime directory before deployment. Physical voice
acceptance is requested separately; API and rendering tests are not speaker tests.
